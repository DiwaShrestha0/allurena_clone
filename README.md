# Allurena — coded clone

A responsive recreation of the Allurena Webflow landing page using plain HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a browser, or use any simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
- The layout, typography, colors, spacing, sections and interactions are recreated from the supplied screenshots and the live public page.
- Product/portrait artwork references the public Webflow-hosted image assets used by the original page.
- Replace those image URLs with locally downloaded assets if you need a fully offline copy.
- No Webflow runtime is required.
